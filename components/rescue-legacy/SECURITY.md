# Security Policy

## Overview

Codex Rescue is local recovery tooling, not a security sandbox or secrets manager.

## Security-Relevant Issues

Security-relevant issues include:
- Unexpected modification of source rollout
- Command replay
- Secret leakage
- Path traversal
- Unintended network access

## Reporting Vulnerabilities

Report security issues via GitHub private vulnerability reporting when available on the repository. Do not report security vulnerabilities in public GitHub issues.
