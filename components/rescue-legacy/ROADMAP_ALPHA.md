# Post-Alpha Roadmap

These are planned areas of work after the initial alpha release. None are implemented yet.

1. **Real compaction recovery corpus** — collect and validate real compaction-related failures
2. **Interactive continuation / TTY portability** — resolve ConPTY/terminal compatibility for automatic fresh continuation
3. **Additional previous Codex version validation** — extend tested format coverage beyond 0.147.0
4. **Multi-GB JSONL bounded-memory stress test** — verify streaming parser performance on very large rollouts
5. **External recovery-report → sanitized fixture workflow** — streamline the process of converting user-submitted reports into regression fixtures
