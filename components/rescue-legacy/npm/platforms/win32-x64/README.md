# codex-rescue-windows-x64

Platform binary package for the Codex Rescue Alpha6 Windows x64 distribution. CI injects the PyInstaller-built executable before `npm pack`; the repository does not contain a prebuilt binary.

The launcher may recognize the historical `codex-rescue-win32-x64` package name for compatibility, but new package-layout qualification uses `codex-rescue-windows-x64` only.
